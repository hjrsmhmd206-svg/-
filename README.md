# Libyan Embassy 3Q — Rules Website

موقع قوانين عربي متجاوب بألوان الأسود والأخضر، مناسب للنشر على GitHub Pages.

## النشر مجاناً من الهاتف أو الكمبيوتر
1. افتح https://github.com/new وأنشئ مستودعاً باسم `libyan-embassy-3q-rules`.
2. اجعل المستودع Public ثم اضغط Create repository.
3. من صفحة المستودع اختر Add file → Upload files.
4. ارفع `index.html` ثم اضغط Commit changes.
5. افتح Settings → Pages.
6. في Build and deployment اختر Deploy from a branch.
7. اختر Branch: `main` والمجلد `/ (root)` ثم اضغط Save.
8. انتظر بضع دقائق وافتح الرابط الذي يظهر في صفحة Pages. غالباً يكون:
   `https://YOUR-USERNAME.github.io/libyan-embassy-3q-rules/`
   استبدل `YOUR-USERNAME` باسم حساب GitHub الخاص بك.

## تعديل القوانين
افتح `index.html` في المستودع واضغط Edit (أيقونة القلم)، ثم عدّل نص القوانين داخل الأقسام. احفظ عبر Commit changes؛ سيتم تحديث الموقع بعد اكتمال النشر.

## ملاحظات
- الموقع ثابت ولا يحتاج قاعدة بيانات أو خادماً خاصاً.
- محتوى القوانين مقترح؛ راجعه ليتوافق مع نظام لعبتك وسيرفرك.
- أي مستودع Public قد تكون محتوياته متاحة للجميع.
